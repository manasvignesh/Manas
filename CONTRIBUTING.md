# Contributing to MANAS

Thank you for helping make synthetic simulations more transparent and useful.

1. Open an issue describing behavior changes or substantial features.
2. Create a focused branch and keep domain boundaries intact.
3. Add tests, especially reproducibility and integrity tests.
4. Run `pytest` and a representative CLI simulation.
5. Explain assumptions and never present synthetic distributions as real population statistics.

New population packs must include metadata, limitations, and provenance. New behavior factors must remain inspectable. Reasoning providers must return structured output and remain optional.

By participating, you agree to follow the code of conduct and license your contribution under the Apache License 2.0.
